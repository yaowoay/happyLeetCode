# 543. 二叉树的直径

> [LeetCode 原题链接](https://leetcode.cn/problems/diameter-of-binary-tree/)

## 题目描述

给你一棵二叉树的根节点，返回该树的 直径 。

二叉树的 直径 是指树中任意两个节点之间最长路径的 长度 。这条路径可能经过也可能不经过根节点 root 。

两节点之间路径的 长度 由它们之间边数表示。

### 示例 1

```text
输入：root = [1,2,3,4,5]
输出：3
解释：3 ，取路径 [4,2,1,3] 或 [5,2,1,3] 的长度。
```

### 示例 2

```text
输入：root = [1,2]
输出：1
```

### 提示

- 树中节点数目在范围 [1, 104] 内
- -100 <= Node.val <= 100

## 原文解题记录

我的思路：

这个root[]构造的二叉树是层序遍历，输出的结果是从左到右最长的一条路径，那怎么让它们最长呢，那就左子树经过的节点数最多加上右子树经过的节点数最多，长度好说，就是节点数-1，那左右子树经过的节点数怎么算呢，那就从左右子树最底层节点开始回溯，一直回溯到根节点，看走了多少步？两个指针？直到节点的前驱节点为root？

遍历左子树后遍历右子树，no！广度优先 bfs

实际上，我们只需要知道每个节点的**左子树的最大深度**和**右子树****的最大深度**，这两个值相加就是经过该节点的最长路径长度（节点数），再减1就是边数。

所以正确的做法是：**递归地计算每个节点的****深度，同时更新全局最****大直径**。

为什么要递归遍历左右子树以各节点为根时的最大深度？以根节点为根时，左右子树的深度不就最大了吗

根节点处的左子树深度 + 右子树深度确实是一个**候选**答案。但是，**直径不一定经过根节点。**

我们要得到根节点所在树的深度，而题目给我们的原函数只装了一个根节点，那我们是不是能只用原函数去完成我们的递归呢？

**只用原函数，不用任何辅助函数 ****求不出来****本题**。因为：

你需要知道每个节点的左右子树深度

计算深度本身就需要递归遍历

你不可能既计算直径又同时计算深度，还不拆成两个函数

分析完全后，回到这里，我们需要初始定义一个全局直径cnt，初始为0，然后调用depth，传入我们题中给的root，调用后返回最后结果所需要的cnt。

Ok，现在我们要额外定义一个辅助函数，depth遍历根节点所代表的子树，里面都做了些什么？我们需要得到左右子树的最大深度，并且需要得到左右最大深度之和+1表示最大直径。

Ok，我们开始想递归，深度为一个数，它为int类型。左右子树怎么表示呢，基于之前的习题，已经知道左右子树为节点的两个成员，节点可以用根节点指示:root->left,root->right;

leftdepth = depth(root->left)；

rightdepth = depth(root->right);

maxdepth = max(maxdepth,leftdepth+rightdepth) ;从这里我们得到我们最终的答案

不断遍历到新的根节点，看以新的根节点为拐点的直径有没有变大，变大那么就更新把新一轮的左右子树的深度加起来，没有变大就还是上一个maxdepth。

然而我们的depth函数返回的是什么不要忘了，返回的是左右子树的深度，左右子树的深度是什么，是**以某节点为****根****左右子****树里树的****左或右子树****最深的那个深度的最大值****。**

return max(leftdepth,rightdepth) + 1;
