# 15. 三数之和

> [LeetCode 原题链接](https://leetcode.cn/problems/3sum/)

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

### 示例 1

```text
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0。
不同的三元组是 [-1,0,1] 和 [-1,-1,2]。
注意，输出的顺序和三元组的顺序并不重要。
```

### 示例 2

```text
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0。
```

### 示例 3

```text
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0。
```

### 提示

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

---

## 解题思路

### 总体思路

三数之和的核心是：

1. 固定一个数，转化为两数之和问题。

2. 用双指针或哈希表找另外两个数。

3. 关键难点：去重。

### 逐步思考

第一步：排序

- 为什么？排序后可以用双指针，并且方便跳过重复元素。

第二步：固定第一个数

- 遍历数组，固定 nums[i] 作为第一个数。

- 然后在 i+1 到末尾之间用双指针找剩下的两个数。

第三步：双指针找两数之和等于目标值

- 目标值 = 0 - nums[i]

- 左指针 l = i + 1，右指针 r = n - 1

- 根据 nums[l] + nums[r] 与目标值的比较移动指针。

第四步：去重

- 当 nums[i] == nums[i-1] 时跳过，避免重复三元组。

- 找到一组解后，左右指针也要跳过重复元素。


### 易错点提示

1. 必须先排序，否则双指针和去重都无法实现。

2. 固定第一个数时，如果它大于0可以直接break，因为后面都是正数，和不可能为0。

3. 找到一组解后，要同时移动左右指针，并跳过重复值。

### 总结

这道题的套路是：排序 + 固定一个数 + 双指针找剩余两个数 + 三重去重（外层循环去重、内层双指针去重）。
