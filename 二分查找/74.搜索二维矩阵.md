# 74. 搜索二维矩阵

> [LeetCode 原题链接](https://leetcode.cn/problems/search-a-2d-matrix/)

## 题目描述

给你一个满足下述两条属性的 m x n 整数矩阵：

- 每行中的整数从左到右按非严格递增顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 target ，如果 target 在矩阵中，返回 true ；否则，返回 false 。

你必须编写一个时间复杂度为 O(log(m * n)) 的解决方案。

### 示例 1

```text
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
输出：true
```

### 示例 2

```text
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
输出：false
```

### 提示

- m == matrix.length
- n == matrix[i].length
- 1 <= m, n <= 100
- -104 <= matrix[i][j], target <= 104

---

## 原文解题记录

**方法****一****：二分查找**

由于矩阵的每一行是递增的，且每行的第一个数大于前一行的最后一个数，如果把矩阵每一行拼在一起，我们可以得到一个递增数组。

<p align="center"><img src="../images/二分查找/74.搜索二维矩阵/image2.jpeg" alt="image2" width="322"></p>

例如示例 1，三行拼在一起得a=[1,3,5,7,10,11,16,20,23,30,34,60]

由于这是一个**有序**数组，我们可以用二分查找判断target是否在matrix中。

代码实现时，并不需要真的拼成一个长为mn的数组a，而是将a[i]转换成矩阵中的行号和列号。例如示例1，i=9对应的a[i]=30，由于矩阵有n=4列，所以a[i]在⌊ i/n⌋=2 行，在 i mod n=1 列。

一般地，有a[i] = matrix[ ⌊i/n⌋ ][ i mod n]

下面用的**开区间**二分，其它写法也可以。

class Solution {

public:

bool searchMatrix(vector<vector<int>>& matrix, int target) {

int m = matrix.size(), n = matrix[0].size();

int left = -1, right = m * n;

while (left + 1 < right) {

int mid = left + (right - left) / 2;

int x = matrix[mid / n][mid % n];

if (x == target) {

return true;

}

(x < target ? left : right) = mid;

}

return false;

}

};

**总思路 **

二维矩阵的行列已知，mid / n 得到行号，mid % n 得到列号，这样就可以把二维坐标映射到一维下标上，直接用标准二分模板搜。

**关键解释 **

int mid = l + (r - l) / 2;

l 初始为 -1，r 初始为 m*n

这种写法是**左开右****开区间** (l, r)，循环条件 l + 1 < r 保证区间内至少有一个元素

(r-l) /2防止(l+r)/2可能导致的整数溢出（虽然本题数据范围不大，但这是好习惯）

最终mid就是当前二分的中点下标

**步骤梳理 **

初始化左边界 l = -1，右边界 r = m * n

当 l + 1 < r 时循环：

计算中点 mid

映射到二维坐标 matrix[mid/n][mid%n]

等于 target → 返回 true

小于 target → 更新左边界 l = mid

大于 target → 更新右边界 r = mid

循环结束没找到 → 返回 false

**复杂度分析**

时间复杂度：O(log(mn))，其中 m 和 n 分别为 matrix 的行数和列数。

空间复杂度：O(1)。

**方法二：排除法**

该方法也适用于240. 搜索二维矩阵II。

注：也可以从矩阵左下角开始，方法类似。

class Solution {

public:

bool searchMatrix(vector<vector<int>>& matrix, int target) {

int m = matrix.size(), n = matrix[0].size();

int i = 0, j = n - 1;

while (i < m && j >= 0) { // 还有剩余元素

if (matrix[i][j] == target) {

return true; // 找到 target

}

if (matrix[i][j] < target) {

i++; // 这一行剩余元素全部小于 target，排除

} else {

j--; // 这一列剩余元素全部大于 target，排除

}

}

return false;

}

};

**复杂度分析**

时间复杂度：O(m+n)，其中 m 和 n 分别为 matrix 的行数和列数。

空间复杂度：O(1)。

**总结**

**这道题妙在可以把二维矩阵拉直成一维矩阵，另外还有x如何表示的也值得学习。**

- 行号 = mid / n（每行有 n 个元素，除以 n 就知道在第几行）

5 / 4 = 1 → 第1行

- 列号 = mid % n（除以 n 的余数就是在一行中的第几个）

5 % 4 = 1 → 第1列

**问：****为什么官方题解的二分查找的中间位置计算都是(high-low)/2+low，为什么不直接写(****high+low****)/2**

答：数据比较大的时候high+low可能会溢出，但是(high-low)/2+low不会溢出

**二分查找模板**

**LeetCode**

- **左****闭右闭**** [l, r] **

初始化：l = 0, r = size - 1

循环条件：l <= r

mid取法：mid = (l + r) / 2（下取整）   或者l + (r-l)/2;

更新规则：l = mid + 1，r = mid - 1

特点：mid检查后直接排除，最标准最常用

- **左闭右闭上****取整 [l, r] **

初始化：l = 0, r = size - 1

循环条件：l < r

mid 取法：mid = (l + r + 1) / 2（上取整）

更新规则：l = mid，r = mid - 1

特点：专门用于**找****右边界**的场景，配合l = mid避免死循环

**为什么要上取整？ **

当 l = 0, r = 1 时，下取整 (0+1)/2 = 0，如果执行 l = mid，则 l 还是 0，死循环。上取整 (0+1+1)/2 = 1，执行 l = mid = 1，循环结束。

- **左****闭右开**** [l, r) **

初始化：l = 0, r = size

循环条件：l < r

mid 取法：mid = (l + r) / 2（下取整）

更新规则：l = mid + 1，r = mid

特点：右边界是开区间，不包含 r，所以 r = mid 没问题

- **左开右开**** (l, r) **

初始化：l = -1, r = size

循环条件：l + 1 < r

mid 取法：mid = l + (r - l) / 2

更新规则：l = mid，r = mid

特点：左右都是开区间，mid不用±1，适合找边界

**对比 **

| 模板 | 初始化 | 循环条件 | mid取法 | 更新方式 | 用途 |
| --- | --- | --- | --- | --- | --- |
| 左闭右闭 | l=0, r=size-1 | l <= r | (l+r)/2 | l=mid+1, r=mid-1 | 标准查找 |
| 左闭右开 | l=0, r=size | l < r | (l+r)/2 | l=mid+1, r=mid | 标准查找 |
| 左开右开 | l=-1, r=size | l+1 < r | (l+r)/2 | l=mid, r=mid | 找边界 |
| 左闭右闭上取整 | l=0, r=size-1 | l < r | (l+r+1)/2 | l=mid, r=mid-1 | 找右边界 |
| 左闭右开上取整 | l=0, r=size | l < r | (l+r+1)/2 | l=mid, r=mid-1 | 找右边界（少见） |

左闭右开上取整这个模板**基本不存在**，因为逻辑矛盾。

**为什么矛盾****：**左闭右开区间[l, r)，**右边界r本身就不在搜索范围内。**

上取整(l+r+1)/2是为了配合l=mid避免死循环，但在左闭右开中，更新规则是r=mid（因为r是开区间，mid可以被排除到右边）。

问题是：上取整会让mid偏向右边，当l和r相邻时，mid=r，但r本身不在区间内，取到了一个无效位置。

**举例 **

l = 0, r = 1：

mid = (0+1+1)/2 = 1

matrix[1]越界或根本不在搜索范围内

**AcWing**

AcWing的l<r风格更适合**找****边界**：第一个>=target的位置、最后一个<=target的位置等

**AcWing**** 整数二分的两套模板 **

AcWing的整数二分并不是用l<=r+l=mid+1, r=mid-1，而是用l<r配合不同的mid取法和更新规则：

**模板****一****（找左边界/第一个满足条件的）**：

int l = 0, r = n - 1;

while (l < r)

{

int mid = l + r >> 1;      // 下取整

if (check(mid)) r = mid;   // 满足条件往左缩

else l = mid + 1;

}

**模板二（找右边界/最后一个满足条件的）**：

int l = 0, r = n - 1;

while (l < r)

{

int mid = l + r + 1 >> 1;  // 上取整

if (check(mid)) l = mid;   // 满足条件往右缩

else r = mid - 1;

}

这两个模板的共同点是：

都用 l < r

循环结束后 l == r，就是答案，不需要额外检查

区别只在于 mid 取整方向和更新规则

**LeetCode****里在更新左右指针之前，先找到目标值并输出结果。**

**左闭右闭上****取整 [l, r] ****针对本题的修补方案**

本题如果用刚才**左闭右闭上****取整**模板，循环结束后会漏掉最后一个元素。

**问题 **

当l == r时，循环条件l < r不成立，直接跳出，但l指向的元素还没检查。

比如matrix = [[1,3]]，target = 3：

l = 0, r = 1

mid = (0+1+1)/2 = 1，x = 3，返回true

但如果target = 1：

l = 0, r = 1

mid = 1，x = 3，target < x → r = 0

此时l = 0, r = 0，循环结束，返回false（实际应该是true）

**修正 **

两种方法：

**方法****一**：循环结束后补一个检查

return matrix[l/n][l%n] == target;

**方法二**：改循环条件为 l <= r

while (l <= r)

{

int mid = (l + r + 1) / 2;

int x = matrix[mid / n][mid % n];

if (x == target) return true;

if (x > target) r = mid - 1;

else l = mid + 1;

}

注意改成l <= r 后，l = mid会导致死循环，所以必须改成l = mid + 1，此时上取整也没必要了，直接用下取整更简洁。
