# happyLeetCode

## 📖 关于这个仓库

大家好！这里是 **Happy LeetCode** 🎉

本仓库对算法小白友好，适合从**0 基础**开始刷题的小伙伴。在刷题的过程中，我做了这样一件事：

📚 **翻阅了大量题解**，把那些最热门、最经典、最容易理解的解法挑出来

💡 **筛选了评论区最有价值的经验和小技巧**

✍️ **加入了自己的理解和优化思路**

最后整理成我认为**最易读、最好懂、最完整的C++版本**，放在这里分享给大家。

---

## ✨ 特点

| 特点 | 说明 |
|------|------|
| **多解法对比** | 暴力 → 优化 → 最优，一步步走通 |
| **注释详细** | 每行C++代码都有解释，不怕看不懂 |
| **精选题解** | 只收录最热门的思路，不堆砌无用解法 |
| **踩坑总结** | 把容易错的点和边界情况都标出来 |
| **排版清晰** | 代码、思路、复杂度分析一目了然 |

---

## 🚀 如何使用

```bash
# 克隆仓库
git clone https://github.com/yaowoay/happyLeetCode.git

# 进入目录
cd happyLeetCode

# 打开你感兴趣的题目，一起学习吧！
```

每个题目文件包含：
- 题目描述&力扣链接
- 多种C++解法（含时间/空间复杂度分析）
- 带重点注释的C++代码
- 易错点&面试要点
